# 파도메이커 블로그 (지킬 버전)

깃허브 페이지에 올리면 지킬(Jekyll)이 이 파일들을 읽어서 블로그 페이지를 자동으로 만들어 줍니다.

## 폴더 구조

| 파일·폴더 | 하는 일 |
| --- | --- |
| `_config.yml` | 블로그 이름, 설명, 글 주소 모양 같은 전체 설정 |
| `_layouts/default.html` | 모든 페이지가 같이 쓰는 틀 (메뉴, 꼬리말) |
| `_layouts/post.html` | 글 한 편의 틀 (날짜, 제목, 이전 글·다음 글) |
| `_posts/` | 내 글이 들어가는 곳. 글 한 편이 파일 하나 |
| `index.html` | 첫 화면. 글 목록이 자동으로 만들어짐 |
| `style.css` | 디자인 (색, 글꼴, 간격) |

## 새 글 쓰는 법

1. `_posts` 폴더의 글 하나를 복사해요.
2. 파일 이름을 `날짜-영어제목.md`로 바꿔요. 예: `2026-11-03-robot.md`
   - 날짜 형식이 틀리면 글이 목록에 나타나지 않아요.
3. 맨 위 `---` 사이의 머리 정보(제목, 태그, 읽는 시간, 한 줄 요약)를 바꿔요.
4. 그 아래에 본문을 마크다운으로 써요.
5. 커밋하고 1~2분 뒤 새로고침하면 첫 화면 목록에 새 글이 맨 위에 나타나요.

`index.html`은 고칠 필요가 없어요.
