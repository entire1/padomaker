# 파도메이커 홈페이지

인스타그램처럼 보이는 피드와 블로그처럼 읽히는 제작 기록을 합친 개인 홈페이지예요.
이 폴더의 파일을 전부 `아이디.github.io` 저장소에 올리면 바로 열립니다.

## 폴더 구조

| 파일·폴더 | 하는 일 | 자주 고치나요? |
| --- | --- | --- |
| `posts.js` | 게시물 목록. 새 게시물은 여기에 추가 | 자주 |
| `posts/` | 긴 글(제작 기록) 한 편이 파일 하나 | 글 쓸 때 |
| `index.html` | 첫 화면. 프로필과 소개 글 | 가끔 |
| `style.css` | 색, 글꼴, 간격 같은 디자인 | 가끔 |
| `app.js` | 첫 화면을 그리는 코드 | 거의 안 고침 |
| `.nojekyll` | 깃허브가 파일을 그대로 쓰게 하는 표시. 숨김 파일이라 안 보이거나 빠져도 사이트는 정상 동작 | 안 고침 |

## 짧은 게시물 올리기 (인스타처럼)

`posts.js`를 열고 `POSTS = [` 바로 아래에 한 덩어리를 추가해요.

```js
{ date:"2026.11.03", tag:"레고", art:"lego", bg:"#fbf1d3",
  title:"제목", caption:"짧은 설명" },
```

## 긴 글 올리기 (블로그처럼)

1. `posts` 폴더의 글 파일 하나를 복사해서 새 이름으로 저장해요. 예: `posts/robot.html`
2. 새 파일에서 제목, 날짜, 본문을 바꿔요.
3. 맨 아래 "지난 글 / 다음 글" 링크도 알맞게 고쳐요.
4. `posts.js`에 게시물을 추가하고 `url:"posts/robot.html", minutes:4`를 함께 적어요.

## 진짜 사진 쓰기

1. `images` 폴더를 만들고 사진을 올려요.
2. `posts.js`에서 `art:"..."` 대신 `photo:"images/사진.jpg"`라고 적어요.
3. 얼굴, 이름표, 학교가 보이는 사진은 올리지 않아요.

## 수정했는데 안 바뀌어요

- 커밋하고 1~2분 기다린 뒤 `Ctrl + Shift + R`로 새로고침해요.
- 게시물이 통째로 사라졌다면 `posts.js`에서 쉼표(,)나 따옴표(")가 빠지지 않았는지 확인해요.
